# 💉 Vaccine Registration System

A full-stack web application for managing vaccine registration and appointments with secure role-based authentication.

## 🚀 Features

* User & Admin Authentication (JWT)
* Vaccine Management
* Vaccination Centre Management
* Appointment Booking & Cancellation
* User Profile Management

## 🛠️ Tech Stack

* **Frontend:** Angular 15
* **Backend:** Spring Boot 2.7.6
* **Security:** Spring Security & JWT
* **Build Tools:** Maven, Angular CLI

## ▶️ Run the Project

### Backend

```bash
mvn spring-boot:run
```

### Frontend

```bash
npm install
ng serve
```

Open: `http://localhost:4200`
